About CodeCraft

An Interactive Compiler Design and Code Analysis Platform engineered for Third-Year Bachelor of Engineering in Computer Science and Engineering (Fifth Semester TEC assignment).

Academic Context & Purpose

In traditional undergraduate computer science education, compiler construction courses frequently rely on abstract theory or legacy CLI utilities (e.g. Lex, Flex, Yacc) which provide limited visual feedback during the intermediate stages of code translation.

CodeCraft bridges this pedagogical gap by providing an end-to-end interactive developer lab. Students can write or load C-subset code, execute multi-stage compilation in a sandboxed Python environment, and immediately inspect generated tokens, visual abstract syntax trees, multi-scope symbol tables, and linearized Three-Address Code quadruples.

Full-Stack Technology Architecture

Backend Framework
Python 3.13 & Django 6.0

Standard Django architecture with modular apps (accounts, compiler_lab, dashboard, learning), robust ORM models, CSRF defense, and custom execution engines.

Database Layer
SQLite 3 ORM

Persistent analysis history models, user ownership isolation, JSONFields for serialized tokens, ASTs, and quadruples, and automated migration seeding.

UI & Styling
Bootstrap 5.3 & Custom CSS

Dark navy aesthetic with indigo/violet/cyan accents, glassmorphism cards, responsive layouts for mobile and desktop, and dual dark/light theme toggle.

Visualization & Charts
CodeMirror, Mermaid & Chart.js

In-browser CodeMirror syntax-highlighted editor, dynamic Mermaid.js flowchart rendering for ASTs, and Chart.js dashboards for compiler execution metrics.

Key Learning Outcomes & Competencies

1. Lexical Pattern Recognition:
Mastered deterministic finite automata (DFA) state transitions, token categorization, line/column coordinate tracking, and error recovery for invalid symbols.
2. Context-Free Parsing & AST Construction:
Designed predictive recursive-descent parsing algorithms that resolve operator precedence climbing and construct navigable abstract syntax trees.
3. Multi-Scope Symbol Management:
Implemented block-scoped symbol tables to track variable lifetimes, detect undeclared identifier usage, and perform compile-time type verification.
4. Intermediate Code Synthesis & Optimization:
Formulated Three-Address Code generation with quadruples, temporary register allocation, jump label routing, and machine-independent constant folding passes.
