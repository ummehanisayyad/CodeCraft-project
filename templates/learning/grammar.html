Formal Specification

Edu-C Language Subset & BNF Grammar

The formal syntax specification implemented by the CodeCraft compiler. Fully documented with supported tokens, production rules, operator precedence, and design boundaries.

Supported Language Constructs
  • Data Types: int, float, char, string, bool, void
  • Variable Declarations: With and without initializers (e.g. int x = 10;, float y;)
  • Assignments: Simple (=) and compound (+=, -=, *=, /=)
  • Arithmetic Operators: +, -, *, /, %
  • Relational Operators: ==, !=, <, <=, >, >=
  • Logical Operators: && (AND), || (OR), ! (NOT)
  • Conditional Statements: if (condition) stmt else stmt
  • Loop Constructs: while (condition) stmt
  • Block Scoping: Nested code blocks enclosed in { ... }
  • Comments: Single-line (// ...) and multi-line (/* ... */)
Intentionally Excluded Constructs

To maintain focus on core Third-Year Compiler Design concepts, the following advanced C features are omitted:

  • Preprocessor Directives: #include, #define, and macro expansions.
  • Raw Pointers & Dereferencing: *ptr, &var, and pointer arithmetic.
  • Composite Types: struct, union, and enum definitions.
  • Dynamic Memory Allocation: malloc(), calloc(), and free().
  • Complex For Loops: for (init; cond; step) (use while loops instead).
  • Switch / Case Statements: (represented through nested if-else chains).

Backus-Naur Form (BNF) Production Rules

Context-Free Grammar 
/* 1. Program Structure */
<program>            ::= <statement_list>
<statement_list>     ::= <statement> <statement_list> | ε

/* 2. Statements */
<statement>          ::= <var_decl>
                       | <assignment_stmt>
                       | <if_stmt>
                       | <while_stmt>
                       | <return_stmt>
                       | <block>
                       | <expr_stmt>
                       | ';'

<var_decl>           ::= <type> IDENTIFIER ( '=' <expression> )? ';'
<type>               ::= 'int' | 'float' | 'char' | 'string' | 'bool' | 'void'

<assignment_stmt>    ::= IDENTIFIER <assign_op> <expression> ';'
<assign_op>          ::= '=' | '+=' | '-=' | '*=' | '/='

<if_stmt>            ::= 'if' '(' <expression> ')' <statement> ( 'else' <statement> )?
<while_stmt>         ::= 'while' '(' <expression> ')' <statement>
<return_stmt>        ::= 'return' ( <expression> )? ';'
<block>              ::= '{' <statement_list> '}'
<expr_stmt>          ::= <expression> ';'

/* 3. Expressions & Precedence Hierarchy (Tightest to Loosest) */
<expression>         ::= <logical_or>

<logical_or>         ::= <logical_and> ( '||' <logical_and> )*
<logical_and>        ::= <equality> ( '&&' <equality> )*
<equality>           ::= <relational> ( ( '==' | '!=' ) <relational> )*
<relational>         ::= <additive> ( ( '<' | '<=' | '>' | '>=' ) <additive> )*
<additive>           ::= <multiplicative> ( ( '+' | '-' ) <multiplicative> )*
<multiplicative>     ::= <unary> ( ( '*' | '/' | '%' ) <unary> )*
<unary>              ::= ( '!' | '-' | '+' ) <unary> | <primary>

/* 4. Terminals & Primaries */
<primary>            ::= IDENTIFIER
                       | INT_LITERAL
                       | FLOAT_LITERAL
                       | STRING_LITERAL
                       | CHAR_LITERAL
                       | 'true'
                       | 'false'
                       | '(' <expression> ')'

Operator Precedence & Associativity

Precedence Level Operators Description Associativity
1 (Highest) ( ) Parenthesized Grouping Left to Right
2 !, - (unary), + (unary) Logical NOT, Unary Negation Right to Left
3 *, /, % Multiplication, Division, Modulo Left to Right
4 +, - Addition, Subtraction Left to Right
5 <, <=, >, >= Relational Comparisons Left to Right
6 ==, != Equality & Inequality Left to Right
7 && Logical AND (short-circuit) Left to Right
8 || Logical OR (short-circuit) Left to Right
9 (Lowest) =, +=, -=, *=, /= Assignment Operations Right to Left
