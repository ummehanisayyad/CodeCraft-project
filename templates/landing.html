Sequential Architecture

The Classical 6-Stage Compiler Pipeline

Every input program traverses through well-defined phases to verify syntactic legality, enforce semantic contracts, and synthesize intermediate instructions.

01
Lexical Analysis
Scanner

Transforms raw stream into typed tokens, tracking line & column coordinates.

02
Syntax Analysis
Parser

Predictive recursive descent validates BNF grammar into an Abstract Syntax Tree.

03
Semantic Check
Type Checker

Constructs hierarchical symbol tables, checks declarations, and catches type flaws.

04
Intermediate Code
ICG

Linearizes AST into Three-Address Code instructions and 4-tuple quadruples.

05
Code Optimization
Optimizer

Executes compile-time constant folding and algebraic simplification passes.

06
Target Overview
Codegen

Maps intermediate quadruples to memory layout, register bounds, and target instructions.

Platform Capabilities

Engineered for Deep Academic Understanding

Read Formal BNF Grammar
Detailed Lexical Token Table

Inspect every token with token sequence number, precise lexeme, lexical category badge, line number, column number, and clear categorization explanations.

Interactive AST & Mermaid Graphs

Visualize syntax trees through native Mermaid.js flowcharts, printable ASCII text trees, and expandable JSON node representations to trace operator precedence and statement hierarchies.

Scope-Aware Symbol Table

Tracks identifiers across global and nested block scopes. Computes memory offsets, verifies type compatibility, detects undeclared variables, and flags duplicate declarations.

Three-Address Code & Quadruples

Generates explicit TAC instructions (`t0 = a + b`) alongside classic 4-tuple Quadruple records `(Op, Arg1, Arg2, Result)` with temporary tracking and jump labels for branches and loops.

Constant Folding & Simplification

Includes a dedicated machine-independent optimization pass demonstrating compile-time constant arithmetic evaluation and algebraic identity reductions (`x + 0 => x`).

Safe Execution & Persistent History

All code is evaluated inside a custom Python compiler engine without executing arbitrary machine code or OS commands. User history is safely isolated via SQLite database models.
